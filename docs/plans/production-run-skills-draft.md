# Production Run, Campaign Skills, and candidate reuse

Vixel UGC should borrow the useful production narrative from agent-led creative tools without becoming a general chat product. Add one Production Run surface that makes the current campaign route, provider job state, approvals, candidate result, and delivery lineage understandable in one place.

Add four bounded Campaign Skills: Product Review, Problem to Demo, Founder Story, and Faceless Explainer. A skill is a persisted planning choice that shapes Creative Brief generation and fallback copy. It is not an autonomous workflow, provider selection, or permission to spend.

Allow an existing image candidate to be reused as the campaign's explicit product or creator reference. Reuse must preserve the candidate's provider/model/signature lineage, create a receipt, and never call a provider by itself. Video reuse is out of scope for this first slice.

Keep paid image/video submission, exact-input approval, billing entitlement, job ledger, and deployment feature flags unchanged. Do not add website generation, public MCP/CLI, multiple visible agents, fake social metrics, arbitrary plugins, or automatic posting.

The interface should remain a restrained dark production console. The result preview is primary; Director reasoning and operational state are supporting evidence. Desktop and mobile must both keep the existing navigation usable.
